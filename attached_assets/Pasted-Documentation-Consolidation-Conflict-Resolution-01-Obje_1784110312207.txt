==================================================
DOMAIN DECISION
==================================================

The Mezanya domain model is now defined as follows.

There are THREE completely different concepts.

--------------------------------------------------

1.

Financial Transaction

This is the financial truth.

It changes balances.

It participates in reports.

It participates in budgets.

It participates in analytics.

Once deleted, its financial effect is reversed.

After deletion it no longer exists as an active transaction.

--------------------------------------------------

2.

Recovery History (Undo History)

This is NOT financial history.

This is NOT part of the Financial Ledger.

Its only purpose is:

- temporary recovery
- undo
- rollback
- recent edits

It stores snapshots of:

- edited transactions
- deleted transactions
- important temporary recovery information

It exists only for a limited retention period.

Example:

14 days.

After expiration it is permanently deleted.

Recovery History never participates in:

- balances
- reports
- analytics
- budgeting

--------------------------------------------------

3.

Activity Log

Activity Log is separate from Recovery History.

It records only important administrative events.

Examples:

Budget created.

Budget modified.

Jar created.

Jar deleted.

Goal modified.

It is NOT intended to log every UI action or application setting.

It also follows its own retention policy.
