===========================================================
WHAT IS A SINGLE SOURCE OF TRUTH
===========================================================

A business value should have exactly one authoritative source.

Examples of possible violations:

Stored balance
+
Transaction history

Stored remaining amount
+
Calculated remaining amount

Stored totals
+
Derived totals

Cached values
+
Real values

Multiple representations of the same financial state.
