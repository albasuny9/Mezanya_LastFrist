- Never modify code unless explicitly instructed.

--------------------------------------------------

When investigating a bug

You must:

1. Trace the complete execution flow.

2. List every file involved.

3. List every method involved.

4. Identify the exact root cause.

5. Distinguish between:

• Confirmed
• Likely
• Unknown

6. Produce a report inside:

docs/project/investigations/

using the BUG id.

--------------------------------------------------

When reviewing architecture

Never propose implementation.

Only answer:

- Is this duplicated?
- Is this obsolete?
- Is this inconsistent?
- Is this still referenced?
- Can this safely move to legacy?
